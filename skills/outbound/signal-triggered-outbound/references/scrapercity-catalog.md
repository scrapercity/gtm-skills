# ScraperCity Tool and Price Catalog

Generated by `scripts/sync-catalog.mjs` from the published `scrapercity` npm package, version 1.0.19.
A later package version with the same tools, prices and CLI commands leaves this file unchanged.
Do not edit by hand. Run `node scripts/sync-catalog.mjs` to refresh, and `--check` in CI to catch drift.
Prices are per result and are deducted from the wallet. When this file and scrapercity.com/pricing disagree, the live site wins.

## Run lifecycle

Every scraper follows the same pattern: start, poll, download.

1. `POST /api/v1/scrape/{slug}` returns `{ runId }`.
2. `GET /api/v1/scrape/status/{runId}` returns `{ status, handled, requested, outputUrl }`. Status is `RUNNING`, then `SUCCEEDED`, `FAILED` or `CANCELLED`.
3. `GET /api/downloads/{runId}` returns the CSV once the run has SUCCEEDED.

Apollo runs can take from hours up to several days. Register a webhook at app.scrapercity.com/dashboard/webhooks instead of polling; it fires when a run reaches SUCCEEDED or FAILED. If you must poll an Apollo run, check at most once an hour.

## Error codes

| Code | Meaning | What the agent should do |
|---|---|---|
| 401 | Missing or invalid API key | Stop and ask for a valid key. |
| 402 | Wallet balance too low | Run `check_wallet`, report the shortfall, wait for the user. |
| 403 | Account cancelled or a charge is processing | Stop and tell the user. |
| 409 | Same search submitted moments ago | Use the earlier run instead of resubmitting. |
| 429 | Rate limited | Back off, then retry once. |
| 503 | Temporarily unavailable, or a database search ran too long | Narrow the database search (add a location, size band or fewer titles), or retry later. |

## Input schemas

### `scrape_apollo`

- `url` (required): string. Apollo.io search URL with Filters 1.0 format
- `count`: number. Number of leads to scrape (500-50,000)
- `fileName`: string. Custom filename for export (max 50 chars)

### `scrape_website_finder`

- `domains` (required): string[]. Array of company domains to search for the given job title
- `jobTitle` (required): string. Job title to find at each domain (one title per request)
- `autoValidateEmails`: boolean. Automatically validate each found email for deliverability
- `autoFindMobiles`: boolean. Automatically look up a mobile number for each found contact

### `find_people`

- `name`: string[]. Names to search
- `email`: string[]. Email addresses to search
- `phone_number`: string[]. Phone numbers to search
- `street_citystatezip`: string[]. Addresses to search
- `max_results`: number. Max results per search

### `scrape_distress_list`

- `search` (required): string. Target market: city + state, or ZIP code
- `distressTypes`: string[]. Signals to include: preForeclosure, foreclosure, auction, bankOwned
- `maxItems`: number. Max properties to return (1-500)

### `validate_emails`

- `emails` (required): string[]. Array of email addresses to validate

### `scrape_maps`

- `searchStringsArray`: string[]. Array of search terms to find businesses
- `locationQuery`: string. City, state, or address for the search area
- `customGeolocation`: object. Alternative to locationQuery - bounding box coordinates
- `maxCrawledPlacesPerSearch`: number. Maximum results per search term
- `url`: string. A Google Maps search link, instead of searchStringsArray and locationQuery. Its search words become the keywords and the place in them the location ("thai restaurants vegas" runs "thai restaurants" in Las Vegas, Nevada). With no place in the words, the map area the link shows is searched. The response says what it ran in search_translation. searchStringsArray, locationQuery or customGeolocation sent with it are used instead of the matching part of the link.

### `scrape_airbnb`

- `mode`: string. Scraping mode: "city", "single", or "bulk"
- `city`: string[]. Cities to search (for city mode). Europe countries only. Format: "City, Country". The country is required to disambiguate city names.
- `listingUrl`: string. Single Airbnb listing URL (for single mode)
- `bulkListings`: string[]. Array of listing URLs (for bulk mode)
- `maxPages`: number. Max pages per city (city mode only)
- `checkin`: string. Check-in date (YYYY-MM-DD)
- `checkout`: string. Check-out date (YYYY-MM-DD)
- `onlyProHosts`: boolean. Only return professional hosts
- `onlyUniqueEmails`: boolean. Deduplicate results by email

### `scrape_bizbuysell`

- `startUrls` (required): string[]. Array of BizBuySell URLs (search pages or individual listings)
- `maxItems`: number. Maximum number of listings to extract
- `datasetName`: string. Dataset name for deduplication across runs

### `scrape_crexi`

- `startUrls` (required): string[]. Array of Crexi URLs. Three forms are supported: (1) a property search or list URL (https://www.crexi.com/properties?...); (2) a city or market search copied from the Crexi search bar (https://www.crexi.com/search?... with a city or market set as the location) - these are automatically scoped to that location; (3) a broker directory URL (https://www.crexi.com/resources/find-a-broker/...). Set your filters (property type, price, cap rate) on Crexi first, then copy the URL. A Crexi map view with no location set (a panned or zoomed map only, with no city or market chosen) is not supported and returns a 400 asking you to search a specific city or market first.
